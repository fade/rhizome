#+TITLE: Rhizome configuration reference
#+STARTUP: showall

This reference lists every configuration key rhizome reads. For how
the configuration file loads and how =configure= merges groups, see
[[file:manual.org::*Configuration][Configuration]] in the user manual.

* Conventions

Every key belongs to a group, and a key's path is the group followed
by the key: =(:bar :height)= is the =:height= key of the =:bar=
group. Set a key by passing its group to =configure=:

#+begin_src lisp
(rhizome:configure '(:bar (:height 24)))
#+end_src

In the tables:

- Type :: =boolean= is =t= or =nil=. =colour= is a string of the form
  ="#rrggbb"=. =command= is a shell command string, run with
  =bash -c=. =seconds= and =pixels= are numbers.
- Default :: the value in effect when the key is not set. A key
  marked (unset) has no value in the default configuration, and the
  default shown is the value the code uses in its place.
- Applies :: when a change takes effect. /live/ means on the next
  redraw or window event. /restart/ means at the next start of the
  window manager. /next connection/ means for each connection opened
  after the change. Bar settings reach the running bar process live
  (see [[*The bar process][The bar process]]).

A =configure= call merges each top-level group key by key, so setting
one key keeps the group's other keys. Inside a group, a list of bare
keywords, such as a module list, replaces the old list whole. See the
manual's merge rules.

* The bar process

The bar runs as a separate process and reads
=~/.config/rhizome/config.lisp= when it starts. After that the window
manager sends it the =:bar=, =:modules=, and =:theme= settings and the
active theme in the snapshot it writes for the bar, so a =configure=
or =reload-config= call reaches the running bar within one poll, with
no restart. A change to =:height= or =:margin= recreates the bar's
surface inside the same process.

* Colours

Every colour comes from the theme selected with =(:theme :name ...)=:
roles such as =:background= and =:accent=, and elements such as
=:bar-background= or =:launcher-match=, set under
=(:theme (:roles ...))= and =(:theme (:elements ...))=. See "Theming"
in README.org. The colour keys from before themes (for example
=(:bar :background)= or =(:launcher :accent)=) still work for one
release; each prints a warning naming its element.

* :bar

The status bar.

| Key                  | Type    | Default             | Applies     | Effect                                                                                                                           |
|----------------------+---------+---------------------+-------------+----------------------------------------------------------------------------------------------------------------------------------|
| =:enabled=           | boolean | =t=                 | live        | Show the bar. =nil= hides it without stopping its process; MOD+B toggles this key.                                               |
| =:height=            | pixels  | =20=                | live        | Height of the bar. The window manager reserves this plus twice =:margin= at the top of the output.                               |
| =:margin=            | pixels  | =8= (unset)         | live        | Space between the bar and the output's top, left, and right edges, and below the bar.                                            |
| =:padding=           | pixels  | =6=                 | live        | Inset of the left and right segments. With a non-zero =:corner-radius= the inset is the radius plus this.                        |
| =:corner-radius=     | pixels  | =10= (unset)        | live        | Corner radius of the bar; 0 draws a plain rectangle. Also the corner radius of the message window and the prompts, 8 when unset. |
| =:opacity=           | number  | =0.9=               | live        | Opacity from 0.0 to 1.0 of the bar, the message window, and the prompts.                                                         |
| =:active-glow=       | boolean | =nil= (unset)       | live        | With =:active-screen=, light a glow in the =:bar-outline-active= colour around the current output's bar.                         |
| =:active-glow-radius= | pixels | =8= (unset)         | live        | How far the glow reaches past the bar, from 4 to 12.                                                                             |
| =:interval=          | seconds | =0.15=              | live        | How often the bar checks its modules for changes. The bar redraws only when a module's text changes.                             |
| =:modules=           | plist   | see below           | live        | The modules of each segment: =(:left (...) :center (...) :right (...))=.                                                         |
| =:workspaces= =:gap= | pixels  | =8= (unset)         | live        | Space after each workspace number. Set it as =(:bar (:workspaces (:gap 8)))=.                                                    |

Colours are theme elements; see Colours above.

The default module layout is:

#+begin_src lisp
(:left (:workspaces :layout :windows)
 :center (:clock)
 :right (:tray :network :volume :battery))
#+end_src

A segment lists module names, =:tray=, and =(:icons (ENTRY ...))=
blocks. Module names are =:workspaces=, =:layout=, =:windows=,
=:focused=, =:recording=, =:clock=, =:battery=, =:volume=,
=:network=, and =:display=. An unknown name draws nothing. Each icons
entry is a property list:

| Key               | Type    | Effect                                                                                |
|-------------------+---------+---------------------------------------------------------------------------------------|
| =:icon=           | string  | An icon name, found as a PNG in the hicolor theme, or an absolute path to a PNG file. |
| =:on-click=       | command | Run on a left click.                                                                  |
| =:on-scroll-up=   | command | Run on scrolling up.                                                                  |
| =:on-scroll-down= | command | Run on scrolling down.                                                                |

Example:

#+begin_src lisp
(rhizome:configure
 '(:bar (:height 28
         :margin 4
         :corner-radius 10
         :modules (:left ((:icons ((:icon "flameshot" :on-click "flameshot gui")))
                          :workspaces :layout)
                   :center (:clock)
                   :right (:recording :tray :network :volume :battery :display)))))
#+end_src

* :modules

Settings for individual bar modules, one property list per module
name. Every module accepts =:on-click=, =:on-scroll-up=, and
=:on-scroll-down=. All keys apply live.

| Key                         | Type    | Default                                              | Effect                                                                                                                                    |
|-----------------------------+---------+------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------|
| =(:clock :format)=          | string  | ="%a %d %b %H:%M"=                                   | Clock format. Codes: =%H= =%M= =%S= =%d= =%m= =%y= =%Y= =%a= =%A= =%b= =%B=. The part after the last space is drawn in the accent colour. |
| =(:battery :interval)=      | seconds | =5=                                                  | Time between battery readings.                                                                                                            |
| =(:volume :interval)=       | seconds | =5=                                                  | Time between =wpctl= readings.                                                                                                            |
| =(:volume :on-click)=       | command | ="pavucontrol"=                                      | Run on a click.                                                                                                                           |
| =(:volume :on-scroll-up)=   | command | ="wpctl set-volume -l 1.0 @DEFAULT_AUDIO_SINK@ 5%+"= | Run on scrolling up.                                                                                                                      |
| =(:volume :on-scroll-down)= | command | ="wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"=        | Run on scrolling down.                                                                                                                    |
| =(:network :interval)=      | seconds | =10=                                                 | Time between =nmcli= readings.                                                                                                            |
| =(:network :on-click)=      | command | ="nm-connection-editor"=                             | Run on a click.                                                                                                                           |
| =(:display :interval)=      | seconds | =10= (unset)                                         | Time between =brightnessctl= readings.                                                                                                    |
| =(MODULE :on-click)=        | command | =nil= (unset)                                        | Run on a left click on MODULE.                                                                                                            |
| =(MODULE :on-scroll-up)=    | command | =nil= (unset)                                        | Run on scrolling up over MODULE.                                                                                                          |
| =(MODULE :on-scroll-down)=  | command | =nil= (unset)                                        | Run on scrolling down over MODULE.                                                                                                        |

A click on =:workspaces= always switches workspace, and clicks and
scrolls on =:tray= go to the tray item, so those two modules ignore
the action keys.

#+begin_src lisp
(rhizome:configure
 '(:modules (:clock (:format "%H:%M")
             :display (:on-click "rhizome-cmd display-menu"))))
#+end_src

* :animations

Merged key by key, including the per-kind groups.

| Key                      | Type         | Default           | Applies | Effect                                                                    |
|--------------------------+--------------+-------------------+---------+---------------------------------------------------------------------------|
| =:enabled=               | boolean      | =t=               | live    | Animate window movement. =nil= turns every kind off.                      |
| =:duration-ms=           | milliseconds | =200=             | live    | Length of a glide: expose, floats, maximize, and a return to the tiling.  |
| =:workspace-duration-ms= | milliseconds | =160=             | live    | Length of the slide-in on a workspace switch. =0= switches with no slide. |
| =:easing=                | keyword      | =:ease-out-cubic= | live    | =:ease-out-cubic=, =:linear=, or =:ease-in-out=.                          |
| =:workspace=             | group        | =(:enabled t)=    | live    | The slide-in on a workspace switch.                                       |
| =:expose=                | group        | =(:enabled t)=    | live    | Windows gliding into and out of the expose grid.                          |
| =:float=                 | group        | =(:enabled t)=    | live    | Floating windows gliding on float, move, unfloat, and maximize.           |

Each kind group takes these keys:

| Key            | Type         | Default | Effect                                                                                                    |
|----------------+--------------+---------+-----------------------------------------------------------------------------------------------------------|
| =:enabled=     | boolean      | =t=     | =nil= turns this kind off and leaves the others on.                                                       |
| =:duration-ms= | milliseconds | unset   | Length of this kind's glide. Unset, the slide takes =:workspace-duration-ms= and the others =:duration-ms=. |

=nil= in place of a kind group, as in =(:expose nil)=, also turns that
kind off.

#+begin_src lisp
(rhizome:configure '(:animations (:enabled t :duration-ms 150 :easing :linear)))
;; keep the workspace slide, glide floats faster, and drop expose motion
(rhizome:configure '(:animations (:float (:duration-ms 120)
                                  :expose (:enabled nil))))
#+end_src

* :window-rules

A list of rules, applied in order when a window opens and again when
its title or application ID changes; the first rule that matches
applies. Default =()=. A =configure= call replaces the
whole list.

| Key           | Type    | Effect                                                                                                   |
|---------------+---------+----------------------------------------------------------------------------------------------------------|
| =:match=      | string  | Regular expression, matched without regard to case.                                                      |
| =:key=        | keyword | Field =:match= tests: =:app-id= (default), =:title=, =:any= (application ID or title), or =:identifier=. |
| =:wse=        | list    | A window selection expression, used in place of =:match=.                                                |
| =:workspace=  | integer | Workspace to open on.                                                                                    |
| =:follow=     | boolean | With =:workspace=, switch to that workspace.                                                             |
| =:float=      | boolean | Open floating.                                                                                           |
| =:fullscreen= | boolean | Open fullscreen.                                                                                         |
| =:output=     | integer | Output to open on, counting from 1 left to right, then top to bottom.                                    |
| =:layout=     | keyword | Layout name set as the first output's current layout.                                                    |

#+begin_src lisp
(rhizome:configure
 '(:window-rules ((:match "firefox" :workspace 2 :follow t)
                  (:match "pavucontrol" :float t)
                  (:wse (:and (:app-id "foot") (:title "scratch")) :float t))))
#+end_src

* :idle

Read once, when the window manager starts.

| Key           | Type    | Default       | Applies | Effect                                                                                                                             |
|---------------+---------+---------------+---------+------------------------------------------------------------------------------------------------------------------------------------|
| =:lock-after= | seconds | =300= (unset) | restart | Run =swaylock -f= after this many idle seconds. =nil= or 0 turns off this idle manager.                                            |

* :ipc

| Key                    | Type    | Default     | Applies         | Effect                                                                |
|------------------------+---------+-------------+-----------------+-----------------------------------------------------------------------|
| =:enabled=             | boolean | =t=         | restart         | Listen for commands on =$XDG_RUNTIME_DIR/rhizome.sock=.               |
| =:client-idle-seconds= | seconds | =5= (unset) | next connection | Drop a client that neither sends nor reads its replies for this long. |

The socket serves one client at a time, so a client that stops
reading or sending keeps every other client waiting until it is
dropped. Time a client spends waiting for its command to finish does
not count. Each drop writes one line to the log, naming the reason
and the bytes the client has not read. The setting takes effect for
the next connection.

* :swank

Accepted for configurations written for the earlier swank server.
While the =:slynk= group equals its default, the =:enabled= and =:port=

is changed, =:swank= is ignored.

|------------+---------+---------+---------+-------------------------|
| =:enabled= | boolean | =t=     | restart | As =(:slynk :enabled)=. |
| =:port=    | integer | =4005=  | restart | As =(:slynk :port)=.    |

* Variables

These settings are Lisp variables rather than configuration keys. Set
them in the configuration file with =setf=.

| Variable                     | Default                           | Effect                                                                                                        |
|------------------------------+-----------------------------------+---------------------------------------------------------------------------------------------------------------|
| =rhizome:*mod*=              | Super (=(:mod4)=)                 | The user modifier. Change it with =set-user-mod=, which also moves the default bindings.                      |
| =rhizome:*modifier-map*=     | Meta to =:mod1=, Super to =:mod4= | Logical modifiers in key specs mapped to river modifiers. Change it with =set-modifier=.                      |
| =rhizome::*workspace-count*= | =9=                               | Workspaces per output.                                                                                        |
| =rhizome::*enable-tap*=      | =t=                               | Turn on tap-to-click on touchpads. One, two, and three finger taps click the left, right, and middle buttons. |
| =rhizome::*enable-tap-drag*= | =t=                               | Turn on tap-and-drag on touchpads.                                                                            |

Variables written with =::= are internal to the =rhizome= package.
